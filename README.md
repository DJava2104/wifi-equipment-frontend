# Wi-Fi equipment frontend

SPA на `React` + `TypeScript` (сборщик `Vite`) с компонентами `React-Bootstrap`.
Интерфейс для **гостя**: просмотр услуг (Wi-Fi роутеров) — их частоты, стандарта Wi-Fi и максимальной скорости.
Данные карточек берутся только из коллекции `mock`-объектов (`src/modules/mock.ts`), бэкенд не используется.

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на <http://localhost:3000>.

## Общие элементы всех страниц

- **Корпус телефона** — экран 9:16 со скруглёнными углами, стиль страниц из лаб. 1.
- **Заголовок страницы** сверху: «Плитка» или «Телеметрия».
- **Навигационная панель** снизу из 4 пунктов:

| Пункт | Адрес | Доступность |
|---|---|---|
| 📱 Лента | `/feed` | доступен |
| ➕ Добавление | — | недоступен (серый) |
| 📒 Плитка | `/` | доступен |
| 👤 Вход | — | недоступен (серый) |

Пункт текущей страницы выделен фиолетовым цветом. При наведении на доступный пункт появляется розовый фон.

## Страница «Лента» — `/feed` и `/feed/:id`

Одна услуга на весь экран.

- `/feed` — первая услуга коллекции, `/feed/:id` — услуга с указанным id.
- Если услуги с таким id нет, показывается первая услуга коллекции.

| Элемент | Тип | Назначение |
|---|---|---|
| «Телеметрия» | заголовок | — |
| Видео | фон | видео услуги на весь экран (автовоспроизведение, без звука, по кругу); если поле пустое — видео по умолчанию |
| «Частота … ГГц» | текст | диапазон частот роутера |
| «Макс. скорость … Мбит/с» | текст | максимальная скорость передачи данных |
| ➡️ | кнопка | переход к следующей услуге (после последней — снова первая) |
| ♥ и число | значок | количество лайков (для гостя только просмотр) |
| Название, стандарт Wi-Fi, описание | текст | название, стандарт и описание услуги (описание обрезано до 2 строк) |
| «Ещё» / «Меньше» | кнопка | раскрывает и сворачивает описание |

## Страница «Добавление»

Пункт navbar «Добавление» серый и не нажимается, сама страница в этой лабораторной не реализована (интерфейс только для гостя). Состав страницы по проекту (лаб. 1):

| Элемент | Тип | Назначение |
|---|---|---|
| 📷 Фотография | поле (файл) | изображение услуги |
| 🎥 Видео | поле (файл) | видео услуги |
| «Название устройства» | поле (текст) | название услуги |
| «Далее» | кнопка | создание черновика услуги |
| Частота (ГГц) | поле (число) | рабочая частота роутера |
| Макс. скорость (Мбит/с) | поле (число) | максимальная скорость передачи данных |
| Стандарт Wi-Fi | поле (текст) | стандарт роутера, например Wi-Fi 6 (802.11ax) |
| Антенны | поле (текст) | количество антенн |
| Описание | поле (текст) | описание услуги |
| «Опубликовать» | кнопка | публикация услуги |

## Страница «Плитка» — `/`

Каталог услуг карточками в две колонки и фильтр по частоте.

| Элемент | Тип | Назначение |
|---|---|---|
| «Плитка» | заголовок | — |
| Ползунок «от … ГГц» | поле (range) | минимальная частота, 2,4–6 ГГц, шаг 0,1 |
| Ползунок «до … ГГц» | поле (range) | максимальная частота, 2,4–6 ГГц, шаг 0,1 |
| «По частоте» | кнопка | применяет фильтр: остаются услуги с частотой в выбранном диапазоне, значения попадают в адрес `/?freq_min=…&freq_max=…` |
| «Найдено: N» | текст | количество найденных услуг |
| Карточка услуги | ссылка | изображение (или изображение по умолчанию), название, стандарт Wi-Fi, «частота · антенны», макс. скорость, ♥ лайки; нажатие открывает услугу в «Ленте» |

При открытии страницы показываются все услуги. Если оставить диапазон 2,4–6 ГГц и нажать «По частоте», снова показываются все. Если ничего не найдено — надпись «Оборудование не найдено».

## Страница «Вход»

Пункт navbar «Вход» серый и не нажимается, сама страница в этой лабораторной не реализована (аутентификации в этой лабораторной нет). Состав страницы по проекту:

| Элемент | Тип | Назначение |
|---|---|---|
| Логин | поле (текст) | имя пользователя |
| Пароль | поле (пароль) | пароль пользователя |
| «Войти» | кнопка | аутентификация пользователя |

```
  DefaultImage.svg              изображение по умолчанию
  DefaultVideo.mp4              видео по умолчанию

  main.tsx                      точка входа, подключение Bootstrap
  App.tsx                       роутер: маршруты «Плитки» и «Ленты»
  Routes.tsx                    адреса и подписи пунктов navbar
  AppLayout.tsx                 общий макет: корпус телефона, страница, navbar
  MobileApp.css                 стили из лаб. 1
  pages/TilePage.tsx            страница «Плитка»
  pages/FeedPage.tsx            страница «Лента»
  components/TabBar.tsx         нижняя навигационная панель
  components/FrequencyFilter.tsx фильтр по частоте
  components/RouterCard.tsx     карточка услуги
  modules/routersApi.ts         тип Router и функции получения данных из mock
  modules/mock.ts               mock-коллекция услуг
  modules/defaults.ts           изображение и видео по умолчанию
```
